# ✅ Vue.js To-Do List

A simple yet flexible to-do list application built using Vue 3 and Vite. This project demonstrates the use of components, props, slots, directives, and scoped styling in Vue.

## 📁 Project Structure

```
To-do-list-main/
└── labb-2/
    ├── index.html                  # HTML entry point
    ├── package.json                # Project metadata and dependencies
    ├── vite.config.js              # Vite configuration
    ├── .eslintrc.cjs               # ESLint config
    ├── .prettierrc.json            # Prettier config
    ├── public/
    │   └── favicon.ico             # Favicon
    ├── src/
    │   ├── App.vue                 # Main Vue component
    │   ├── main.js                 # Entry point script
    │   ├── assets/                 # CSS and static assets
    │   │   ├── base.css
    │   │   ├── main.css
    │   │   └── logo.svg
    │   └── components/             # Reusable components
    │       ├── LoopDirective.vue
    │       └── SlotContainer.vue
    └── .vscode/                    # Editor settings
        └── extensions.json
```

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Navigate to the `labb-2` directory:

```bash
cd labb-2
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
